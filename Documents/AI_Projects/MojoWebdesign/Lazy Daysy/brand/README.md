# LazyDaysy — Brand Assets

Centrale plek voor alle logo-varianten. Gebruik per situatie:

| Bestand | Wanneer gebruiken |
|---|---|
| `lazydaysy-logo-original.png` | Bronbestand met crème achtergrond. Voor print, drukwerk, vlakke achtergronden. Niet voor web. |
| `lazydaysy-logo-transparent.png` | Volledig logo (bloem + "LazyDaysy" + tagline) met transparante achtergrond. Voor visitekaartjes, e-mailhandtekening, social media post-templates waar je het complete merk-beeld wil tonen. |
| `lazydaysy-icon.png` | Alleen het bloem-icoon, transparant. Voor app-icoon, favicon, website-nav, social media profielfoto. Wordt nu gebruikt in `index.html`, `offerte.html`, `restaurants.html`. |

## Kleuren (officieel)
- Sky blue petals: `#A8D5E2`
- Mint green wordmark: `#B8E0C2`
- Sunshine yellow center: `#F5D061`
- Cream background: `#FAF6F0`
- Ink (tekst-donker): zie `--ink` in CSS

## Nog te doen
- SVG-vectorversies laten maken (voor signage, voertuigsticker, groot drukwerk).
- Donkere modus / monochrome variant voor situaties met weinig contrast.
- Favicon (`.ico` 32x32) genereren uit `lazydaysy-icon.png`.
